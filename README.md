# 陈谦 · 个人作品集

视觉与数字设计作品展示，包含品牌视觉、UI / UX、平面设计与 IP 形象。

## 浏览

直接打开 `index.html`。页面、字体与作品图片均使用本地资源。

## GitHub Pages

在仓库 Settings → Pages 中选择 **Deploy from a branch**，使用 **main / (root)**。
仓库包含 `.nojekyll`，可直接发布已生成的静态文件。

## 修改

- `src/projects.json`：作品内容。
- `src/main.jsx`：页面结构与交互。
- `src/styles.css`：视觉样式。
- `assets/`：发布所需的页面资源。

安装依赖后运行 `npm run build`，即可重新生成静态页。

作品与个人资料由作者提供。仓库内第三方依赖保留其各自许可证信息。
